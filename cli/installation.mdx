## Runtime requirements

The CLI requires **Bun**, including when the package is installed with npm or pnpm. Node alone does not execute the CLI. The current 0.6.4 milestone was qualified with Bun 1.3.10; the Node SDK/report interfaces were qualified with Node 24.18.0. See the [release record](/docs/reference/release-0-6-4/) for the full qualification boundary.

Install Bun using its [official installation instructions](https://bun.sh/docs/installation), then check the runtime:

```bash
bun --version
```

## Install the CLI

Choose one package manager:

```bash
npm install -g @artemiskit/cli
# or
pnpm add -g @artemiskit/cli
# or
bun add -g @artemiskit/cli
```

## Verify the installed version

```bash
akit --version
akit --help
```

`akit` and `artemiskit` are aliases for the same CLI. Milestone and package versions are independent: the 0.6.4 milestone publishes CLI 0.6.3. Your installed output depends on the selected package version; consult the release's package map when pinning.

## Run without a global install

With Bun installed:

```bash
bunx @artemiskit/cli --help
```

## Before making provider calls

Configure an authorised provider key and a model available to your account. Keep secrets out of scenario files and Git. Model calls may incur provider costs. Workflow validation is offline; preflight can make a bounded provider probe.
