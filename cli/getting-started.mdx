## Quick Install

```bash
npm install -g @artemiskit/cli
```

## Quick Test

```bash
# Set your API key
export OPENAI_API_KEY="sk-..."

# Create a test scenario
cat > hello-world.yaml << 'EOF'
name: hello-world
provider: openai
model: gpt-4o

cases:
  - id: math-test
    prompt: "What is 2 + 2?"
    expected:
      type: contains
      values: ["4"]
EOF

# Run the test
akit run hello-world.yaml
```
