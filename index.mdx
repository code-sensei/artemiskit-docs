## Understand the evidence

Read the [reproducibility guide](/docs/reference/reproducible-evidence/) and [current release record](/docs/reference/release-0-6-4/). Invalid and unavailable workflow measurements remain distinct from eligible passed/failed outcomes. A passing test does not certify legal compliance or guarantee safety.

## Versions and source

The source-backed workflow and package references identify their exact core-repository snapshot. The current recorded release milestone is 0.6.4, with independent package versions (CLI/SDK 0.6.3). Consult its package map rather than treating a milestone number as every package's version.
