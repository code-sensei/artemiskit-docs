## Core Package

The `@artemiskit/core` package provides the foundation for all ArtemisKit functionality:

```typescript
import { createAdapter } from '@artemiskit/core';

// Create a provider adapter
const client = await createAdapter({
  provider: 'openai',
  apiKey: process.env.OPENAI_API_KEY,
});

// Generate a response
const result = await client.generate({
  prompt: 'What is 2+2?',
  maxTokens: 100,
});

console.log(result.text); // "4"
```

## SDK Package

The `@artemiskit/sdk` package provides high-level APIs for evaluation and protection:

```typescript
import { ArtemisKit } from '@artemiskit/sdk';
import { createGuardian } from '@artemiskit/sdk/guardian';

// Programmatic evaluation
const artemis = new ArtemisKit({
  provider: 'openai',
  apiKey: process.env.OPENAI_API_KEY,
});

const result = await artemis.evaluate({
  prompt: 'What is 2+2?',
  expected: { type: 'contains', values: ['4'] },
});

// Runtime protection
const guardian = createGuardian({ mode: 'guardian' });
const protectedClient = guardian.protect(myClient);
```
